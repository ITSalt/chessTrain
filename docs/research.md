# Исследование аналогов и источников

Дата исследования: 9 ноября 2026. Метод: просмотр официальных сайтов, документации и репозиториев. Не выполнялись регистрация/покупка продуктов, практический тест качества, массовая загрузка видео или обучение профилей.

Заявленная функция продукта не означает подтверждённую точность, пригодность API или право переиспользования его внутреннего сервиса. Полное отсутствие аналогов на рынке не утверждается: среди изученных источников не найден весь сценарий «мысли игрока + позиция + аппроксимация выбранного автора».

## Аналоги

| Продукт | Подтверждённое публичным описанием | Как использовать вывод |
|---|---|---|
| [Grandmaster AI](https://grandmasterai.com/chrome-extension) | Запись мыслей на Lichess, расшифровка и воспроизведение аудио по ходам заявлены в индексируемой инструкции | Ближайший аналог capture; прямой просмотр страницы отдавал JS-shell, практическая работа не проверялась |
| [Chessvision.ai](https://chessvision.ai/) | Поиск YouTube по позициям/концепциям, PGN в Board Explorer, синхронная доска | Подтверждает существование связки видео и позиции; интеграционный API не подтверждён |
| [DecodeChess](https://decodechess.com/faq/) | Объяснение понятий и рекомендаций Stockfish | Ориентир качества понятного шахматного объяснения; анализ мыслей и авторский профиль отдельно |
| [WhyThisMove](https://whythismove.com/) | Импорт партий, Stockfish, разговорный разбор; упомянуты Maia и игровые данные | Референс движок + LLM + интерфейс разговора; не доказательство точности каждого объяснения |
| [ChessGPT / ChessCLIP](https://github.com/waterhorse1/ChessGPT) | Исследовательский код, модели и данные, связывающие шахматы и язык | Изучить представления и методику; не принимать готовой основой русскоязычного профиля без оценки |
| [OBS Studio](https://obsproject.com/) | Запись экрана и аудио, Windows/Linux | Резервный ввод и независимая контрольная запись для оценки времени |

Решение make/buy: собственными остаются анализ мыслей, профиль автора, применимость принципов, синхронизация и контракты. Библиотеки и AI API используются для стандартных функций. Закрытый продукт не становится критической зависимостью без подтверждённого API и условий интеграции.

## Первичные технические источники

| Источник | Поддерживаемый вывод |
|---|---|
| [Lichess game export specification](https://github.com/lichess-org/api/blob/master/doc/specs/tags/games/game-export-gameId.yaml) | PGN/JSON, clocks при наличии, задержка ongoing-партии на три полухода; не точная realtime-шина |
| [Lichess Fair Play](https://lichess.org/page/fair-play) | Внешняя помощь во время партии ограничена; граница capture/analysis существенна |
| [Chrome recording guide](https://developer.chrome.com/docs/extensions/how-to/web-platform/screen-capture) | Механизмы записи и offscreen-контекст; микрофон и разрешения конкретного расширения требуют теста |
| [python-chess](https://python-chess.readthedocs.io/en/latest/) | PGN, проверка ходов, состояние доски и UCI |
| [Stockfish](https://stockfishchess.org/use/) | Движок как отдельный компонент, открытый исходный код, GPLv3 |
| [FastAPI](https://fastapi.tiangolo.com/features/) | Типизированный API и публикация OpenAPI |
| [Celery tasks](https://docs.celeryq.dev/en/stable/userguide/tasks.html) | Повторы и подтверждения задач; идемпотентность остаётся ответственностью приложения |
| [pgvector](https://github.com/pgvector/pgvector) | Векторный поиск в PostgreSQL, совместное использование с full-text |
| [react-chessboard](https://github.com/Clariity/react-chessboard) | React-компонент доски; шахматные правила нужно обеспечивать отдельно |
| [YouTube captions.download](https://developers.google.com/youtube/v3/docs/captions/download) | Требуются права редактирования видео; нельзя обещать официальный доступ ко всем чужим субтитрам |
| [Gemini video understanding](https://ai.google.dev/gemini-api/docs/video-understanding) | Мультимодальный анализ видео и временных фрагментов; точность шахматной доски не гарантирована |
| [Gemini YouTube URL](https://ai.google.dev/gemini-api/docs/generate-content/video-understanding) | Документирована работа с URL в preview; необходим альтернативный вход |
| [Claude model overview](https://platform.claude.com/docs/en/models/overview) | Семейства кандидатов для reasoning и диалога; реальные model ID проверяются перед экспериментом |
| [Deepgram models/languages](https://developers.deepgram.com/docs/models-languages-overview) | Поддержка русского языка; качество шахматных терминов требует теста |
| [faster-whisper](https://github.com/SYSTRAN/faster-whisper) | Локальное распознавание, word timestamps; скорость на данном сервере не измерена |
| [BGE-M3 model card](https://huggingface.co/BAAI/bge-m3) | Многоязычное представление текста и рекомендации гибридного поиска; шахматная применимость измеряется отдельно |

Версии и цены не копируются в архитектуру как вечные константы. Перед установкой фиксируются конкретные версии зависимостей и совместимость; перед экспериментом — model ID и тарифный снимок.

Конкретный набор видео не выбран и не просмотрен для извлечения принципов. Документы не утверждают, что какой-либо из авторов предпочитает определённый план, стиль риска или порядок оценки позиции. Эти выводы должны появиться из проверенного корпуса.

## Что остаётся измерить

1. Доступность выбранных роликов и достаточность данных для восстановления позиции.
2. Русскую шахматную транскрипцию, точность временных привязок и цену исправлений.
3. Добавленную пользу профиля относительно общего AI-тренера с движком.
4. Генерализацию на неиспользованные видео и собственные партии пользователя.
5. Производительность и стоимость на реальном сервере и аккаунтах провайдеров.

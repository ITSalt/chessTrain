# ChessTrain — архитектура персонального шахматного тренажёра

ChessTrain сопоставляет позицию, мысли игрока во время партии и модель рассуждений выбранного шахматного автора. Цель — обсуждать качество мышления с условным тренером по материалам Шамиля Арсланова или Матвея Гальченко.

**Состояние: архитектурный комплект v1, 9 ноября 2026.** Требования основаны на обсуждении с владельцем проекта. Технические решения зафиксированы для разработки; качество моделей и доступность конкретного корпуса ещё не проверены. Приложение не реализовано. Документы не являются отчётом об успешных экспериментах.

## Основные решения

- Первая версия для одного пользователя: Windows, Chrome/Edge, Lichess, рапид 1500–2000.
- Во время игры — только запись; обработка и обратная связь — после завершения партии.
- Диалог текстовый, вопросы можно надиктовывать; клонирование голоса не входит в v1.
- Сервер на Unix: Python/FastAPI, PostgreSQL/pgvector, Celery/Redis, Stockfish.
- Интерфейс и расширение: TypeScript/React; локальная запись защищает от недоступности сервера.
- Профиль автора строится из проверенных эпизодов и условных принципов. Источники сохраняются внутри, но не показываются в обычном диалоге.
- Для подготовки базы приоритетно качество. Модель для регулярного разбора выбирается по измерениям качества, цены и задержки.

## Граница готовности

Документация позволяет начать пилот и реализацию инфраструктуры без повторного выбора архитектуры. Она не гарантирует точное воспроизведение мышления автора, безошибочное распознавание видео или определённую стоимость API.

Первое действие разработчика — этап A из [плана разработки](docs/delivery.md): собрать вручную проверенный сквозной пример и измерить добавленную пользу профиля автора. Массовую загрузку архива и дообучение модели не начинать до этой проверки.
